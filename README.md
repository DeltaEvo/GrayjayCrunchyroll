# Crunchyroll (fork mzramna)

Fork do plugin oficial da FUTO para o Grayjay (Android e Desktop com Widevine).

Instalar: `grayjay://plugin/https://raw.githubusercontent.com/mzramna/GrayjayCrunchyroll/main/CrunchyrollConfig.json`

## Filtros de busca (com apenas esta fonte selecionada)
- **Idioma padrão**: "Áudio em …" / "Legenda em …" (usa as configurações *Audio Language* e *Subtitles/CC Language*).
- **Buscar por**: Mídia (idiomas do episódio) ou Criador (idiomas da série).
- **Áudio (dublagem)** e **Legenda**: idiomas específicos (qualquer um dos marcados).
- Os filtros também valem para a aba Creators.

Desenvolvimento: cada mudança em uma branch; durante o teste o `sourceUrl` aponta para a branch e volta para a `main` no merge.

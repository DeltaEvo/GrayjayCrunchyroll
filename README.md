## Grayjay Desktop e idiomas

- Compatível com Grayjay Android e Desktop (instale pela URL `https://mzramna.github.io/GrayjayCrunchyroll/CrunchyrollConfig.json`).
- **Configurações**: idioma dos metadados (padrão Português (Brasil)), idioma de áudio preferido e opção de mostrar na home apenas o áudio preferido.
- **Busca**: filtros de *Áudio (dublagem)* e *Legenda* com vários idiomas, incluindo pt-BR. Buscar canais retorna as séries.
